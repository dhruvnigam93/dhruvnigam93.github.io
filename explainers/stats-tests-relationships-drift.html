Which Test? Relationships & Drift

The framing insight — say this first, always. "Is there a relationship?" splits into two separate questions:

1 · Significancedistinguishable from zero given my n? → a test + p-value
2 · Strengthhow big is it? → an effect size, independent of n

Interviewers who ask "how do you measure the strength" right after you name a test are checking you know these are different things.

2 · Continuous ↔ continuous

Pearson r = cov(X,Y) / (σX·σY). Measures linear association only, in [−1, 1]. Significance under H₀: ρ = 0:

t = r · √(n−2) / √(1−r²)   ~   t-distribution, n−2 df

Worked: r = 0.5, n = 100 → t = 0.5·√98/√0.75 ≈ 5.72 → p ≈ 10⁻⁷.

Same test, three costumes. The t-test on r, the t-test on the slope of y = a + bx, and the regression F-test (F = t²) are identical. "Correlation test or regression test?" is a trick — same object.

Spearman ρ = Pearson computed on ranks. Catches any monotonic relationship, robust to outliers and heavy tails. (Kendall's τ for small n / many ties.)

Strength: |r| itself (rough bands: 0.1 small · 0.3 medium · 0.5 large) and r² = fraction of variance explained.

3 · Binary ↔ continuous

Reframe out loud: "does the distribution of the continuous variable differ between the two groups?" — e.g., session length for churned vs retained.

TestWhat it actually tests
DefaultWelch's two-sample t-testDifference in means. Doesn't assume equal group variances — strictly better default than Student's, costs nothing.
Skewed / outliers / ordinalMann-Whitney UP(X₁ > X₀) ≠ 0.5 — stochastic dominance, not means.

Strength — three interchangeable lenses:

  • Cohen's d = (μ₁ − μ₀) / spooled. Bands: 0.2 small · 0.5 medium · 0.8 large.
  • Point-biserial r — literally Pearson r with the binary coded 0/1. Related to the t statistic by r² = t²/(t² + df): the "correlation" and the "t-test" are again the same object.
  • AUC = P(score of random positive > random negative) — this is the Mann-Whitney U statistic normalized to [0,1]. Great EDA strength readout for one feature vs a binary target: "this feature alone has AUC 0.61."

Direction flip. Predicting the binary from the continuous → univariate logistic regression; the Wald test on the coefficient answers the same association question. Association is symmetric; the test menu depends on which variable you condition on.

4 · Binary ↔ binary

Build the 2×2 contingency table. Chi-square test of independence:

χ² = Σ (O − E)² / E,   E = row total × col total / N,   df = 1 for 2×2

Assumption: all expected counts ≥ 5. Violated (rare events, small n) → Fisher's exact test (exact hypergeometric, no approximation).

Strength:

  • φ (phi) = √(χ²/N) — and φ = |Pearson r| computed on the 0/1 codes.
  • Odds ratio = ad/bc — the stakeholder-friendly one: "users on promo have 3.9× the odds of churning." CI via log OR ± 1.96·SE, SE = √(1/a + 1/b + 1/c + 1/d).
  • Cramér's V = √(χ² / (N·min(r−1, c−1))) — generalizes φ to bigger tables.

The pattern: every row of the master table hides a correlation. cont↔cont → r itself · binary↔cont → point-biserial r · binary↔binary → φ · categorical↔cont → √η². One object, five costumes — saying this out loud is the sign you actually get it.

5 · Categorical (k>2) ↔ continuous

One-way ANOVA: F = MSbetween / MSwithin, df = (k−1, N−k). H₀: all group means equal.

  • With k = 2, F = t² — ANOVA is the t-test generalized.
  • Significant F only says "at least one group differs." Which one → post-hoc pairwise (Tukey HSD) — which is a multiple-testing problem (BH / Bonferroni).
  • Non-parametric: Kruskal-Wallis (generalizes Mann-Whitney).
  • Strength: η² = SSbetween / SStotal — fraction of variance explained by group membership. (ω² is the less-biased version; naming it is a flex.)

6 · Strength vs significance — the trap itself

Test statistics grow like √n — for correlation, t ≈ r·√n. So the p-value is effect size × sample size, entangled. Drag the sliders:

p < 0.05?—

  • n = 1,000,000 and r = 0.01 → t ≈ 10 → p < 10⁻²². Massively "significant," utterly useless — r² says it explains 0.01% of variance. At production scale everything is significant; effect sizes + practical thresholds are the only meaningful filter.
  • Reverse trap: n = 20, r = 0.3, p ≈ 0.2 → "not significant" ≠ "no relationship." It's underpowered. Say: "I'd compute power / needed n before declaring absence."

The answer template: report effect size + 95% CI; use the p-value only as a gate. Never say "there IS a relationship (p<0.05)" without sizing it.

8 · Drift metrics (the "how do you measure drift" follow-up)

Setup: per feature, compare the serving window distribution vs the training reference.

PSI (Population Stability Index) — the industry default:

Bin reference into ~10 quantile bins.
PSI = Σᵢ (aᵢ − eᵢ) · ln(aᵢ / eᵢ)

where e = expected (reference) share in bin i, a = actual (serving) share. It's the symmetrized KL divergence. Smooth zero-count bins with a small ε.

At serving n ≈ 100k, even D ≈ 0.01 gives p ≈ 10⁻⁴ — the KS p-value fires on trivial shifts (Section 6 all over again). That's why monitoring uses PSI/Wasserstein with fixed thresholds, not test p-values.

Alternatives by type
  • Continuous: KS two-sample test (D = max CDF gap) — but prefer effect-size-style metrics with thresholds: PSI, Wasserstein distance (respects magnitude of shift, not just overlap).
  • Categorical: chi-square on category shares, or PSI over categories.
  • Divergences: KL (asymmetric, blows up on zeros) · JS (symmetric, bounded).
Multivariate drift — the domain classifier trick

Correlations can shift while every marginal stays flat. Label reference rows 0, serving rows 1, train a classifier. AUC ≈ 0.5 → no detectable drift; AUC ≫ 0.5 → drift, and feature importances tell you where. This is the strongest advanced mention.

What PSI can't see — concept drift

P(y|x) changing under stable P(x). No input-distribution metric catches it. Catch it with calibration decay (observed vs predicted rate in score bins) and precision/recall on matured labels.

9 · The 30-second answer script

"Depends on the variable types. Continuous–continuous: Pearson correlation, Spearman if I suspect non-linearity or outliers. Binary–continuous: two-sample t-test — Welch's — or Mann-Whitney. Binary–binary: chi-square on the 2×2, Fisher's exact if cells are small. For strength I report an effect size — r or r², Cohen's d, phi or an odds ratio. For significance each test gives a p-value, but with our sample sizes p-values saturate, so I'd lean on effect sizes with thresholds — same reason drift monitoring uses PSI with 0.1/0.25 cutoffs instead of KS p-values."

That last sentence links the whole answer back to production ML — it's the staff-level close.
